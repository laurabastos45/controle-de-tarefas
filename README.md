# 📋 Controle de Tarefas

Sistema web para gerenciamento de tarefas e atividades diárias.

O objetivo do projeto é permitir que usuários organizem suas tarefas, definam prazos, acompanhem o progresso e mantenham suas atividades organizadas.

---

## 🚀 Status do Projeto

🚧 Em desenvolvimento

Este projeto está sendo desenvolvido como parte da disciplina de **Desenvolvimento de Aplicações**.

---

## 🛠 Tecnologias Utilizadas

Frontend:
- React
- Vite
- JavaScript
- HTML
- CSS
- Spring Boot (Backend)
- MySQL (Banco de Dados)

---

## 📌 Funcionalidades Planejadas

- Criar tarefas
- Editar tarefas
- Excluir tarefas
- Definir prioridade
- Definir prazo
- Marcar tarefa como concluída
- Visualizar tarefas em andamento
